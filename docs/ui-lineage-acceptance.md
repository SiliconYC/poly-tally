# 同源统计界面与交互验收

## 设计

保留单层页首、上方统计卡与主面积图、下方两张分析卡。净变化卡使用两个同规格下拉控件：代码/注释/文档/文件，以及日/周/月。构成卡切换语言与仓库；仓库项直接消费后端已折叠的唯一主导组，不在前端相加成员。

普通展示区禁拖选、默认光标和透明文本插入光标；可编辑输入保留选择/编辑/可见插入光标。仓库名称是复制按钮，GitHub外链是独立控件。成功复制完整名称后显示短暂底部提示，不抢焦点；拒绝或不支持Clipboard时明确失败，绝不假成功。

依据：[W3C按钮模式](https://www.w3.org/WAI/ARIA/apg/patterns/button/)、[不移动焦点的状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)、[柱图零基线](https://data.europa.eu/apps/data-visualisation-guide/starting-bars-at-zero)。不借“最佳实践”增加重复说明文字或额外图表。

- 周变化实际为代码−20、注释−5、文档−10、文件−2；日/周/月切换可用，保留真实零线与负值。
- 仓库构成实际为合成组190、独立副仓库30、新仓库15，没有再次加入组成员。
- 真实点击、Enter、Space均成功复制完整Synthetic名称；提示自动消失，焦点留在按钮。
- 普通展示区不可拖选，搜索输入可编辑且Ctrl+A能选中内容；外链独立。
- 桌面及实际400 CSS像素窄视口（普通窗口与125%页面缩放，不冒充真实手机硬件）均检查：顶部2×2，控件38px、箭头16px，两分析卡各360px，无内容横向溢出。
- 清空诚实显示空态，关闭浮层和重置恢复三项。验收后恢复100%缩放和原桌面窗口。

浏览器本地端口与执行工作区不互通，故使用正常HTTPS部署，未改变浏览器安全设置。Clipboard拒绝/不支持仅由单元夹具验证，没有调整真实浏览器权限模拟失败。

## 发现与修正

验收发现空态细节仍保留旧周期title，现已清除并加回归；同源合成项没有单一branch，不再显示“尚无默认分支”，改为“公开/私有 · 同源组”。这两处小修在临时预览后仅单测，正式部署后仍须检查，不能把预览旧版验收记作最终生产全链通过。

界面测试与数据重算是两件事：没有新鲜完整数据时显示pending/incomplete；不能用合成预览或旧快照证明全量采集完成。
