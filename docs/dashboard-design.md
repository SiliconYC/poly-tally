# 数据看板布局

## 当前设计

按用户反馈恢复“统计卡片在上、趋势图在下”的阅读顺序，减少界面文案。

- 只保留一重 Header：Poly Tally、更新时间和刷新。删除宣传标题、副标题及重复导航。
- 筛选之后立即展示六张独立指标卡片；卡片保留指标切换与选中状态。
- 大趋势图位于卡片下方。不再重复展示巨大的当前总量；图表标题旁只保留净变化及规模／占比切换。
- 删除常驻的操作教程、宣传语与重复说明。键盘操作说明及卡片补充信息供辅助技术读取；统计口径集中在默认折叠的“统计说明”中。
- 仓库图层、快照明细及高级筛选按需展开。告警仍明确显示，不为追求简洁隐藏真实数据问题。
- 桌面端月度变化与语言构成并排；仓库表保留搜索、排序、合计与 CSV 导出。窄屏卡片为三列，表格可横向滚动。
- 使用暖白、墨色与克制的青绿。无外部字体或新增依赖，无装饰性动效。

## 保持不变

不改采集器、数据、发布工作流和统计计算。保留 DOM 标识符、筛选、图表范围刷选、键盘与指针交互，以及私有数据边界。首次观测前未知、缺少期初不比较、月度比较仓库范围可能不同等口径仍可查看。

构建器继续为 CSS、入口脚本和完整本地模块图生成统一内容摘要与带摘要的 URL；统计 JSON 路径不变，防止新 HTML 混用旧界面资源。

## 验证

```sh
node --test web/*.test.mjs scripts/*.test.mjs
node scripts/build-site.mjs
```

`web/layout.test.mjs` 锁定单 Header、卡片先于趋势图、无常驻教程字幕、独立卡片样式，并检查应用 DOM 标识、指标、排序控件与统计口径。

结构测试不能替代浏览器验收。须覆盖桌面与 390px 手机布局、页面横向溢出、刷新、筛选和重置、指标切换、图层控制、范围刷选、语言筛选、仓库搜索与导出，并在发布后复验。
