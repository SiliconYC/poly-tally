# 仪表盘升级

## 参考项目与取舍

本次阅读了 `vitro_union_lab` 下的 `代码增长_报告_Qt` 与 `基础_规模统计_Qt`，重点查看了根界面的控件与交互、趋势图的系列设置、面积绘制、时间刷选、工具提示，以及规模视图切换。

| 参考能力 | 对当前项目的价值 | 本次处理 |
| --- | --- | --- |
| 趋势系列独立显隐，多系列悬停提示 | 分清各仓库贡献，解释合计从何而来 | 按仓库堆叠、图例切换、独显、快照明细 |
| 底部概览、左右手柄、窗口平移、双击恢复 | 历史跨度大时能快速检查局部变化 | 迷你趋势与可拖动窗口，补充可键盘操作的日期输入 |
| 行数、文件数等指标切换 | 同一套数据可以回答不同规模问题 | 六项概览卡片可直接切换指标 |
| 月度与最近变化柱状图 | 将长期存量与短期净变化联系起来 | 月度净变化，点击月份放大趋势图 |
| 分类勾选和规模/工作时长视图 | 分类筛选值得迁移，时长需要另一种采集来源 | 仓库图例与语言筛选；不从 Git 提交推断工作时长 |
| 日、月、年粒度 | 控制密集数据的阅读成本 | 存量保留精确快照，变化按月展示；暂不增加多套粒度控件 |
| 纵轴截断与过渡动画 | 对单系列微小变化有帮助 | 堆叠图从零起绘，补充占比模式；避免截断后误读面积 |
| 本地文件导入 | 适合桌面离线工具 | 保持当前自动发布的数据来源，增加当前列表的 CSV 导出 |
| 7/30/90 天平均增长、字数、模组数 | 依赖可比较的期初、项目特有分类或额外采集 | 不把缺失期初当零，不引入当前采集器无法支持的数字 |

参考项目使用 `QPainter` 自绘。本项目继续使用本地原生 `SVG` 与标准浏览器控件，无需运行时图表库、外部字体或 CDN。

## 图表操作

- 趋势图默认按仓库展示堆叠面积，每个快照之后延续存量，保留真实跃升与下降。
- 悬停查看当前时间与仓库贡献；点击固定，再次点击解除。聚焦图表后使用左右方向键、`Home`、`End` 浏览，`Escape` 返回最新。
- 图例点击切换显隐，`Shift` 点击只显示该仓库，“全部显示”恢复。图例只影响趋势图，快照明细显示可见合计；概览、语言构成和列表仍按上方全局筛选计算。
- 拖动底部时间窗口的左右手柄缩放，拖动窗口平移。也可输入 UTC 起止日期；“重置缩放”或双击主图恢复上方所选时间范围。
- “占比”将每个观察点归一为可见仓库总量的百分比，明细仍保留实际行数。
- 语言构成采用环形饼图，悬停或键盘聚焦与右侧明细联动；点击扇区或明细行筛选该语言，“显示全部语言”恢复。小占比语言仍保留精确行数。

首次观测之前的仓库规模保持未知，明细显示“未观测”。面积只绘制已知存量，不将首次观测前的空白解释成零规模。

## 规模与变化口径

`总行数 = 代码行 + 注释行 + 文档行 + 空行`，不包含文件数。它是前端派生指标，采集与私有发布协议不变。混合代码/注释的物理行仍只计为代码行。

顶部概览、语言构成和仓库表显示最新快照；时间筛选控制历史图和变化比较，不将最新规模伪装成历史时点规模。列表默认按总行数降序，隐藏不参与当前范围汇总的仓库。

月度图展示所选时间内最多十二个月的净变化，逐仓库比较月初之前与月末最后已知存量。当月首次出现的仓库缺少期初，不参与当月变化计算；之后月份如有期初则可参与。各月均显示可比仓库数与缺少期初数，部分月份明确标记。月份间比较集合可能不同，因此不将这些柱值解释为整个仓库集合的累计增长。上方的期间净变化仍要求所有所选仓库均有期初快照，否则显示“暂不可比”。

私有仓库仍只有日级规模，不暴露真实提交时刻和提交详情。

## 仓库表与导出

仓库名称去掉账号前缀，保留公开仓库链接。列表同时展示总行数、代码行、注释行、文档行、空行和文件数，各列可独立排序。“最后成功”“状态”“历史/规则”不再占据表格列；采集诊断继续位于折叠的统计口径区域。

列表搜索只筛选当前表格，底部合计和 CSV 导出均对应搜索与排序后的可见行。导出带 UTF-8 BOM，正确转义逗号与引号，并对可能被电子表格当作公式的文本做前缀保护。
