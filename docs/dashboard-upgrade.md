# 仪表盘升级

## 前端工程

页面迁移为 React、TypeScript、Vite 和 Tailwind CSS 工程。基础控件使用本地 shadcn/ui 组件，图表使用 shadcn/ui Chart 容器与 Recharts；仓库表以 TanStack Table 管理表格状态。基础组件源码取自官方 `new-york-v4` registry，`components.json` 记录 `new-york` 风格与路径别名，后续修改在 `web/src/components/ui/` 内维护。

这一组合已覆盖筛选、弹层、表格、提示、反馈和图表容器，不需要额外引入 Tremor。组件和依赖在构建时打包，浏览器运行期间不依赖外部字体或 CDN。

`App` 维护全局筛选与受控时间范围，各视图通过 `props` 和回调联动。趋势图图例显隐、占比模式与快照固定，构成图维度、排序与悬停，以及净变化指标与周期，留在图表局部状态；表格搜索和排序只影响当前列表与导出。各区域复用 `web/model.mjs` 的纯模型与 `web/insights.mjs` 的纯计算导出，逐步迁移渲染，不重写已有统计规则。

## 图表操作

- 趋势图默认按仓库展示堆叠面积，每个快照之后延续存量，保留真实跃升与下降。
- 悬停查看当前时间与仓库贡献；点击固定，再次点击解除。聚焦图表后使用左右方向键、`Home`、`End` 浏览，`Escape` 返回最新。
- 图例点击切换显隐，`Shift` 点击或“只看”按钮只显示该仓库，“全部显示”恢复。图例只影响趋势图，快照明细显示可见合计；概览、规模构成和列表仍按上方全局筛选计算。
- 拖动底部时间窗口的左右手柄缩放，拖动窗口平移。也可输入 UTC 起止日期；“恢复全部历史”或双击主图恢复上方所选时间范围。
- “占比”将每个观察点归一为可见仓库总量的百分比，明细仍保留实际行数。
- 规模构成提供语言与仓库两个维度，环形图与明细联动；点击扇区或明细行筛选相应语言或仓库，使用全局筛选恢复范围。小占比条目保留精确数值，仓库明细提供完整名称复制。

首次观测之前的仓库规模保持未知，明细显示“未观测”。面积只绘制已知存量，不将首次观测前的空白解释成零规模。

## 规模与变化口径

`总行数 = 代码行 + 注释行 + 文档行 + 空行`，不包含文件数。它是前端派生指标，采集与私有发布协议不变。混合代码/注释的物理行仍只计为代码行。

顶部概览、规模构成和仓库表显示最新快照；时间筛选控制历史图和变化比较，不将最新规模伪装成历史时点规模。列表默认按总行数降序，隐藏不参与当前范围汇总的仓库。

周期变化图支持日／周／月，按 UTC 日历分桶，周从周一开始；逐仓库比较期初之前与期末最后已知存量。周期内首次出现的仓库缺少期初，不参与该周期变化计算；之后如有期初则可参与。每个周期显示可比仓库数与缺少期初数，未结束或被筛选窗口截断的周期明确标记为部分周期。各周期的比较集合可能不同，不将柱值解释为整个仓库集合的累计增长。上方的期间净变化仍要求所有所选仓库均有期初快照，否则显示不可比。

私有仓库仍只有日级规模，不暴露真实提交时刻和提交详情。

## 仓库表与导出

仓库名称显示简短名称，保留经过校验的公开 GitHub 链接；复制按钮写入完整仓库名称，私有仓库不生成链接。列表同时展示总行数、代码行、注释行、文档行、空行和文件数，各列可独立排序。复制成功或失败使用反馈提示；采集诊断与规则说明放在统计说明区域。

列表搜索只筛选当前表格，底部合计和 CSV 导出均对应搜索匹配后的全部排序行，跨分页计算。导出带 UTF-8 BOM，正确转义逗号与引号，并对可能被电子表格当作公式的文本做前缀保护。

## 开发与发布入口

```bash
npm ci
npm run dev
```

开发地址使用 `/poly-tally/` 基路径，从 `web/data/stats.json` 读取工作树中的公开空 pending 基线。Vite 的 `publicDir: false` 关闭公共目录自动复制，但不会阻止开发服务器响应源码根目录下已有文件；开发模式不执行私有合并或展示窗口处理。

发布必须使用完整构建入口：

```bash
npm run build
npm run preview -- --port 4187
```

预览地址为 `http://127.0.0.1:4187/poly-tally/`。`npm run build` 先校验完整输入和可选脱敏私有快照，完成合并与 `applyDisplayWindow`，再调用 Vite。最终只向 `site/` 发布入口可达的资源、经过校验的 `data/stats.json`、favicon 和 `.nojekyll`；资源文件使用内容 hash，不复制私有快照、测试源码或旧预览目录。完整输入始终保留，改变显示起点不要求重新采集。

真实数据验收可使用 `POLY_TALLY_REAL_STATS=/tmp/poly-real-stats.json npm run test:e2e`，由浏览器测试对生产站点的数据请求重放已公开的真实数据；源文件和发布输入不变。真实数据不提交到 `dev`，也不用它替换源仓库的空基线。

## 验证入口

```bash
.venv/bin/python -m pytest -q
npm run typecheck
npm test
npm run test:legacy
npm run test:e2e
npm run bench
```

`test:legacy` 保留纯模型、时间对齐、同源组、规则隔离、未知期初、窗口裁剪、CSV 与私有数据安全回归；`npm test` 用于 React 筛选和组件交互。构建集成测试在临时目录执行真实 Vite，检查内容 hash、子路径与未发布源码。浏览器入口用于验证完整页面交互、空态和窄屏布局，性能入口用于测量模型与图表数据准备；运行前按各自配置准备浏览器与数据，是否通过以实际输出为准。
