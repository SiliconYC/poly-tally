- 非编辑文字保留透明光标和禁用选择；搜索、日期输入继续可编辑。
- 指标按钮保留键盘激活、选中语义与可见焦点。
- 构成图和净变化图保持只读，不联动全局筛选或日期范围。
- 历史提示跟随指针、边缘避让、离开清除；固定提示在图表滚出视口后隐藏。
- 保留日期选择、历史缩放、图层显隐、百分比、快照导航、排序、分页、复制与导出。
