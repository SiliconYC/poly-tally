# 低饱和图表与分析布局验收

关联 [Issue #22](https://github.com/SiliconYC/poly-tally/issues/22)。

## 改动

- 仓库与语言统一使用低饱和的跨色相分类色，历史主体为灰蓝，语言圆环主体为灰褐，净变化为灰绿／陶土。历史图层保持不透明纯色，无渐变。
- 阅读文字沿用上一版的中性高对比色，保持浅深主题的 `7:1` 关键文字验收。
- 净变化绘图区从 `280px` 加高至 `432px`，桌面构成区域与其对齐。圆环采用相对半径，`1440px` 视口下实际直径由 `196px` 增至约 `260px`。
- 语言列表视窗从 `288px` 增至 `404px`，真实数据桌面可完整显示 9 行。窄屏布局上下排列，语言名称、数值与百分比保持完整。
- 未增加控件、说明文字或依赖；数据计算和事件处理保持原样。

## 验证

- `npm run typecheck` 与生产构建通过。
- `npm test`：26 项通过；`npm run test:legacy`：117 项通过。
- 真实公开数据的 `npm run test:e2e`：20 项通过，覆盖只读图表、日期缩放、浮层、键盘焦点、非编辑光标、输入编辑、筛选、导出、排序和深浅主题响应式。
- 检查真实数据的桌面与手机浅深主题截图；额外检查 `1280px`、`1200px`、`1024px`、`768px` 与 `320px` 的布局边界。
