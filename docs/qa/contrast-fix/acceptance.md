# 图表与文字对比度修复验收

关联 [Issue #20](https://github.com/SiliconYC/poly-tally/issues/20)。

## 修复范围

- 阅读文字改为中性色；指标标签、指标值、表头、页头时间在浅色与深色模式均以至少 `7:1` 对比度验收。
- 仓库和语言采用区别明确的分类色；默认视图分别以蓝色历史图、橙色语言构成和青绿色净增长区分图表。
- 历史图取消全部渐变定义，使用与仓库图例一致的完全不透明纯色。回归测试检查实际生成的 `SVG` 填充。
- 保留原有布局、控件、数据计算与图表交互。
