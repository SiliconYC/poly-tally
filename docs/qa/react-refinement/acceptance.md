# 仪表盘减法修正验收

日期：2026-10-22。基于 `bf60076` 修正 React 迁移后的交互和设计回退。

## 改动

- 构成图和净变化图移除修改全局状态的回调。点击扇区、明细或柱子都不改变全局筛选、历史窗口或页面滚动位置。
- 移除周期列表、常驻变化明细、卡片解释文字、第二重标题和重复指标下拉框。运行及口径说明、快照明细默认折叠。
- 单 Header、数字层级、选中态、协调的语言配色、细分隔和紧凑分析卡片参考 [Tremor Overview](https://overview.tremor.so/)；继续使用 shadcn/ui 和 Recharts，不引入 Tremor 或另一套图表引擎。
- 历史浮层采用 [Floating UI](https://floating-ui.com/docs/virtual-elements) 的虚拟锚点、`flip`、`shift` 和 `hide`。它随指针定位、避让视口边缘；固定后滚离图表时隐藏。绘图和导航继续单独记忆化，不因快照浏览重建。
- 恢复普通文本的 `user-select: none` 和透明 caret；输入框及可编辑区域保持原生编辑、选择和光标。
- 仓库表默认 100 条，可选 200、500；不足 100 条时不呈现无用分页控件。排序、搜索、合计、公开链接、复制和 CSV 保留。
- 统计函数和私有数据协议不变。未知不转为零；只涉及部分仓库的变化，在悬停提示内用“部分仓库（已统计数／总数）”标明范围，不常驻页面。

## 性能

实测见 `browser-performance.json`，环境为 Chrome 156、macOS arm64、1440px。20 个仓库、10,000 条不同变化快照保留所有变化时点；40 个仓库、100,000 条快照仅精确压缩重复绘图点。快照键盘交互分别约 136ms、131ms，主图与导航的 Profiler 回归仍确保无额外绘图提交。
